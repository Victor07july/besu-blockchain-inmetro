❓ Ajuda e Problemas Comuns

🔧 Problemas de Conexão

❌ Erro: "Contrato não encontrado" ou "Nenhum código no endereço"
  • Verifique se o endereço do contrato no arquivo .env está correto
  • Certifique-se de que o contrato foi deployado na rede
  • Execute: cd dapps/monetiza_co2/scripts/E2 && python3 2_deploy.py
  • Copie o novo endereço para dapps/web-interface/.env
  • Reinicie o servidor Node.js
❌ Erro: "MetaMask não conecta" ou "Rede incorreta"
  • Verifique se o MetaMask está instalado: metamask.io
  • Certifique-se de estar na rede Besu Local (ChainID 1337)
  • Configure manualmente: Configurações → Redes → Adicionar Rede
  • RPC URL: http://localhost:8545
  • ChainID: 1337
⚠️ Erro após reiniciar a rede Besu
  • O MetaMask cacheia transações antigas
  • Solução: MetaMask → Configurações → Avançado → "Limpar dados de atividade e nonce"
  • Ou clique em "Reset Account" nas configurações da conta
  • Recarregue a página do navegador

📤 Problemas ao Criar NFTs

❌ Erro: "Processamento falhou" ou valores incorretos
  • Verifique o formato do CSV: deve ter as colunas corretas
  • Colunas obrigatórias: VIN, ethanol (%), highway (distance), city (distance), behavior_cautious (%), behavior_normal (%), behavior_aggressive (%)
  • Comportamentos devem somar 100%
  • Use ponto (.) como separador decimal, não vírgula
❌ Erro: "Gas limit exceeded" ou "Out of gas"
  • Processe uma linha por vez usando o campo "Linha do CSV"
  • Não tente processar muitas linhas de uma vez
  • Aumente o gas limit no contrato se necessário
